# 面向服务的软件工程：课件内容概览

来源：南京大学教学支持系统课程“面向服务的软件工程”（课程 ID 426）的“课件”区。以下内容根据下载课件的文件名、页数和幻灯片正文整理。

- 课件总数：47 个
- 文件格式：29 个 `.pptx`，18 个旧版 `.ppt`
- 课程主线：服务与服务系统 → SOA → XML/SOAP/WSDL → 服务发现与扩展 → 面向服务分析与设计 → JAX-WS/JAXB 实现

## 一、服务与 SOA 基础

| 文件 | 页数 | 内容简介 |
|---|---:|---|
| `01 Services and Services System.pptx` | 26 | 介绍服务的定义、服务与制造业产品的区别、服务系统的组成与视角，以及 IT 支持的服务和服务生态系统。 |
| `02 Services Computing and Service-Oriented.pptx` | 61 | 回顾命令式、面向对象和基于构件的编程范型，引出面向服务范型、服务库存、服务组合、服务模型，以及面向对象与面向服务的比较。 |
| `03 Service-Oriented Architecture.pptx` | 31 | 讲解 SOA 的概念、服务提供者/请求者/注册中心模型、SOA 的收益、ESB、SOA 参考架构、编排与编舞，以及 SOA 解决方案生命周期。 |

## 二、消息交换、XML 与数据类型

| 文件 | 页数 | 内容简介 |
|---|---:|---|
| `04 Message exchange and Data type.pptx` | 12 | 说明应用之间进行电子信息交换的场景，回顾软件工程与类图，并讨论服务计算中的数据类型、服务合约和数据表示标准化。 |
| `04.1 XML.pptx` | 20 | 介绍 XML 的文本化树结构、基本语法、元素与属性、CDATA/PCDATA、声明、注释和处理指令，以及“格式良好”与“有效”的区别。 |
| `04.2 NameSpace.pptx` | 16 | 解释 XML 元素和属性命名冲突问题，介绍 URI、QName、命名空间声明、作用域、默认命名空间及多命名空间文档。 |
| `04.3 XML Schema.pptx` | 34 | 讲解 XML Schema 的作用、元素/属性声明、出现次数、简单类型与复杂类型、约束面、模型组、全局/局部定义等。 |
| `04.4 DOM Parser.pptx` | 13 | 介绍 DOM 的对象模型、将 XML 整体加载为内存树的处理流程、节点类型、解析器配置、异常处理和文档树导航。 |
| `04.5 SAX Parser.pptx` | 11 | 介绍基于事件的 SAX 解析，说明其适用场景、事件时间线、解析器创建、Content Handler、Error Handler 和状态维护。 |
| `04.6 XSL.pptx` | 11 | 说明为什么需要 XSL，以及 XSL/XSLT 在客户端和服务器端处理 XML、展示 XML 数据中的作用。 |
| `04.7 XPath.pptx` | 20 | 介绍 XPath 的上下文节点、文档树分区、轴、节点测试、谓词和位置路径，用于定位 XML 文档中的节点。 |
| `04.8 XSLT.pptx` | 48 | 详细讲解 XSLT 转换过程、样式表结构、控制元素、模板匹配以及生成 XML 等输出的常用机制。 |

## 三、服务建模、SOAP 与 WSDL

| 文件 | 页数 | 内容简介 |
|---|---:|---|
| `05 Services modeling.pptx` | 5 | 从 XML、命名空间、XML Schema 和 SOAP/WSDL 的关系出发，讨论如何描述、发布、查找和建模 Web Service，以及复合服务和非功能需求。 |
| `05.1 SOAP Basis.pptx` | 26 | 介绍 SOAP 的历史、XML 消息框架、命名空间、消息处理模型、文档式交换、RPC 交互和 SOAP Fault。 |
| `05.2 SOAP Binding.pptx` | 30 | 讲解 SOAP 与底层协议的绑定、功能特性和消息交换模式，重点覆盖 HTTP GET/POST、编码方式、Web 兼容用法和 SMTP 传输。 |
| `05.3 SOAP Extension.pptx` | 38 | 介绍 SOAP 角色、`mustUnderstand`、`relay`、中间节点、SOAP 头块，以及二进制数据、Base64 和 MTOM 优化传输。 |
| `05.4 WSDL Basis.pptx` | 19 | 讲解 WSDL 的基本概念与历史，以及目标命名空间、消息类型、接口、绑定、服务和 WSDL 1.1/2.0 的差异。 |
| `05.5 WSDL InfoSet  Component Model.pptx` | 40 | 介绍 WSDL 2.0 Infoset、规范 Schema、元素顺序、组件模型、导入/包含、故障定义、消息类型和 XML Schema 的嵌入与引用。 |
| `05.6 WSDL Interface  Binding.pptx` | 31 | 详细说明 WSDL 接口语法、接口继承、故障和操作、消息交换模式，以及 SOAP/HTTP Binding 和 GET/POST 序列化。 |
| `05.7 WSDL Extension.pptx` | 50 | 介绍 WSDL 扩展的可选/必需机制、自定义消息交换模式、RPC 风格、消息分派、动态 Web Service，以及预约服务示例。 |

## 四、服务发布、发现与 Web Service 扩展

| 文件 | 页数 | 内容简介 |
|---|---:|---|
| `06 Web Services publishing and Discovery.pptx` | 45 | 介绍 Web Service 发布到注册中心的流程，重点讲解 UDDI 信息模型、API、WSDL 映射，以及分布式 WSIL 发布与发现。 |
| `07 Extension of Web Services.pptx` | 64 | 总览 WS-* 标准族，涵盖安全、可靠消息、策略、资源、事务和管理等扩展，并重点介绍复合服务、BPEL 编排和 WS-Addressing。 |

## 五、面向服务的分析、设计与设计原则

| 文件 | 页数 | 内容简介 |
|---|---:|---|
| `08 Service-Oriented Analysis.pptx` | 61 | 讲解面向服务生命周期、业务逻辑与应用逻辑、服务层次、SOA 交付策略和服务分析流程，并以发票提交、订单履行为例识别业务服务候选。 |
| `09 Service-Oriented Design.pptx` | 77 | 介绍面向服务设计目标和过程，包括服务层选择、核心 SOA 标准、WS-I 基本概要、WSDL 优先设计和以实体为核心的业务服务设计。 |
| `10.1 Principles of Service-Oriented Design I.pptx` | 58 | 重点讲解标准化服务合约和松散耦合原则，讨论服务功能、数据表示、策略、粒度、WSDL/XML Schema 设计及相关风险。 |
| `10.2 Principles of Service-Oriented Design II.pptx` | 66 | 讲解服务抽象原则，覆盖信息隐藏、技术/功能/程序逻辑/服务质量元信息、抽象度量、封装、粒度和抽象级别案例。 |
| `10.3 Principles of Service-Oriented Design III.pptx` | 67 | 讲解服务自治，区分运行时自治与设计时自治，分析服务合约自治、逻辑自治、完全隔离、粒度及错误划分服务范围等风险。 |
| `10.4 Principles of Service-Oriented Design IV.pptx` | 68 | 讲解服务可发现性与可解释性，覆盖发现元信息、设计时/运行时发现、发现度量、服务组合及组合成员与控制器。 |

## 六、服务生命周期与平台实现

| 文件 | 页数 | 内容简介 |
|---|---:|---|
| `11 Development, Testing  ect of Services.pptx` | 14 | 总结服务开发、测试、部署和管理，介绍基于规约的测试、动态性测试、协同验证与确认、可信中介服务等内容。 |
| `12.01 Web Services Platform Architecture.ppt` | 13 | 介绍 Web Services Platform Architecture，包括服务端/客户端调用子系统、Java/XML 序列化、类型映射、部署子系统和部署描述符。 |
| `12.02 JWS Architecture.ppt` | 23 | 讲解 JWS 服务端部署与调用、客户端调用、源代码注解、WSDL/Java 映射、序列化上下文，以及 JAX-WS、JAXB、WS-Metadata 和 WSEE 的关系。 |
| `13.01 Standard JAXB 2.0 Java XML Binding.ppt` | 12 | 介绍 JAXB 2.0 的绑定与映射概念、Schema 编译/生成方式，并以 `simpleOrder` 为例说明 Java/XML 标准绑定。 |
| `13.02 Implementing Type Mappings with JAXB 2.0.ppt` | 9 | 使用已有的 `MySimpleOrder`、`MyAddress` 和 `MyItem` Java 类，说明如何结合自定义代码实现 JAXB 类型映射与序列化。 |
| `13.03 Recursive Framework for Type Mapping.ppt` | 8 | 介绍递归类型映射框架，通过 `Serializer`、订单、地址和商品序列化器拆分复杂对象的映射过程。 |
| `13.04 Implementing Type Mappings with JAXB 2.0 Annotations.ppt` | 11 | 通过 JAXB 注解配置 Java 类、命名空间和字段映射，展示注解方式的 Marshall/Unmarshall 实现。 |
| `13.05 Implementing Type Mappings with JAXB 2.0 Binding Language.ppt` | 11 | 介绍 JAXB Binding Language，在 XML Schema 中加入绑定声明，以生成带注解的 Java 类并处理数据类型转换。 |
| `13.06 Implementing Type Mappings with JAXB 2.0 XmlAdapter Class.ppt` | 14 | 介绍 `XmlAdapter` 对复杂或多变量类型进行拆分、合并和转换的方式，以地址、电话和订单映射为例。 |
| `13.07 JAXB 2.0 for Data Transformation.ppt` | 5 | 介绍使用 JAXB 和 JAX-WS Dispatch 将订单数据转换为客户历史数据的示例流程。 |
| `14.01 JAX-WS Server-Side Architecture.ppt` | 7 | 介绍 Java EE/JAX-WS 服务端架构，以及从客户端获取 WSDL、发送 SOAP 请求到服务端处理和响应的完整调用链。 |
| `14.02 Start from WSDL Using a Service Endpoint Interface.ppt` | 5 | 讲解从既有 WSDL 出发，通过服务端点接口（SEI）和服务实现 Bean（SIB）实现 Web Service 的方式。 |
| `14.03 Providers and XML Processing without JAXB.ppt` | 8 | 介绍 `Provider<T>` 的 Message/Payload 两种模式，展示不依赖 JAXB、直接处理 XML 消息并部署服务的方法。 |
| `14.04 Validation and Fault Processing.ppt` | 21 | 讲解使用 WSDL 中的 Schema 验证输入消息，以及将 Java 异常映射为 SOAP Fault、处理已映射和未映射异常。 |
| `14.05 Server-Side Handlers and Run-time Endpoint Publishing.ppt` | 11 | 介绍服务端 Handler Chain 的配置和执行顺序，以及使用 `Endpoint.publish` 在运行时发布服务并生成/访问 WSDL。 |
| `15.01 JAX-WS Proxies.ppt` | 15 | 介绍 JAX-WS 代理调用，包括 WSDL 到 Java 映射、SEI 注解、生成式/动态代理、`@WebServiceRef` 和动态代理限制。 |
| `15.02 XML Messaging with Raw XML .ppt` | 10 | 通过订单示例介绍原始 XML 消息、定制 JAXB 类、自定义 Java/XML 映射及客户端调用。 |
| `15.03 Asynchronous Invocation.ppt` | 8 | 介绍 JAX-WS 异步调用方式，包括轮询客户端、代理异步方法和回调客户端。 |
| `15.04 Client-Side Handlers.ppt` | 10 | 介绍客户端 SOAP 消息 Handler，以及以编程方式添加 Handler、持久化消息和 Handler 链概览。 |

## 学习顺序建议

建议先按 `01`–`03` 建立服务计算和 SOA 的整体概念，再学习 `04`–`05.7` 的 XML、SOAP、WSDL 技术基础；随后阅读 `06`–`07` 了解发现与扩展，使用 `08`–`10.4` 学习分析、设计及设计原则，最后以 `11`–`15.04` 的生命周期和 JAX-WS/JAXB 实现材料完成技术落地。
