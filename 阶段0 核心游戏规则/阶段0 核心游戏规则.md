## 时间轴长度

初始设计固定为 **7 Tick**。

## 动作阶段的最小语法

核心：**Startup（起手）** 和 **Recovery（收势）** 代表动作的前后摇；动作本身分为防御、位移、攻击、削弱、强化等类型。

- **Startup 起手**：代表角色将要进行动作。若该起手被中断，则该起手所属招式的后续动作全部被中断。
- **Recovery 收势**：代表角色动作结束。
- **Move 位移**：位移动作。
- **Guard 防御**：防御动作，代表角色将会防御敌人攻击。
- **Hit 攻击**：攻击动作，代表角色将会造成伤害。
- **Debuff 削弱**：削弱动作，代表角色将会施加效果削弱敌人。
- **Buff 强化**：强化动作，代表角色将会施加强化效果增强自身或盟友。
- **None 静置**：代表角色什么都不做。
- **Unknown 未知**：未知类型，其效果与当前所有已知动作类型均不同。

### 起手与中断

中断只会由以下情况触发：

1. 部分具有明确“中断”效果的卡牌；
2. 攻击使目标韧性降为 0。

Startup 的结算顺序晚于 Hit。若同一 Tick 中，Hit 或其他可中断效果先结算并成功中断目标正在进行的 Startup，则该 Startup 及其所属招式的后续动作全部取消，不再结算。

## 结算优先级

同一 Tick 内，按照动作优先级依次结算：

1. **优先级 1：Buff / Debuff**
2. **优先级 2：Guard**
3. **优先级 3：Move**
4. **优先级 4：Hit**
5. **优先级 5：Startup / Recovery**

Unknown 拥有独立的内部结算优先级，范围为 **0–5**。Unknown 的具体执行时序不向玩家公开。

### 同一优先级内的结算顺序

同一优先级的动作按以下顺序结算：

1. 玩家；
2. 敌人按照结算时的当前屏幕坐标，从左到右依次结算。

若同一个单位在同一 Tick 内存在多个相同优先级的 Action：

- 玩家按照对应卡牌的出牌顺序结算；
- 敌人的结算顺序在设计该敌人动作时明确指定。

敌人的左右结算顺序依据**当前屏幕坐标**确定，因此敌人发生 Move 后，后续 Tick 的左右结算顺序可能发生变化。

## 时间刻占用规则

一个招式可能在时间轴中占用连续片段，中间也可能存在 **Empty Tick**。

- 玩家可以从任意 Tick 开始放置卡牌。
- 若卡牌放置后有任何动作超出 Tick 7，则该放置操作被阻止。
- 除非卡牌存在特殊说明，同一角色在同一 Tick 只能进行一个操作。
- **Empty Tick** 表示该卡牌在该 Tick 不占用操作位置，因此可以在该 Tick 放置其他卡牌的动作。

例如：

卡牌 A： `Startup → Hit → Empty → Hit → Recovery`

卡牌 B： `Startup → Empty → Empty → Hit → Recovery`

只要两张卡牌的实际非 Empty 动作没有在同一 Tick 发生冲突，就可以在同一回合内共同使用。

## 信息公开原则

敌人的行动全部透明可见。

Unknown 的具体效果和执行时序不会向玩家公开，但 Unknown 的效果与当前所有已知动作类型均不同，并且不会直接或间接在当回合对玩家造成攻击伤害或削韧。

## 卡牌循环机制和基础动作保底

玩家局内所有拥有的牌位于牌库 **Deck**。

对局开始时，玩家所有**非基础牌**进入抽牌堆 **Draw Pile**。

每回合开始时，玩家从抽牌堆中抽取 **Cards Drawn Per Turn** 张非基础牌，默认值为 **5 张**。

### 基础牌

所有基础牌 **Basic Cards** 全程保留在玩家手牌 **Hand** 中：

- 不进入 Draw Pile；
- 不进入 Discard Pile；
- 不会因为回合结束而离开 Hand；
- 即使在回合内被打出，也会立即返回 Hand；
- 因此，同一张基础牌可以在单个回合内反复打出，只要其放置满足时间轴占用规则。

### 普通卡牌

玩家打出的普通卡牌在其对应招式**全部结算完成后**进入弃牌堆 **Discard Pile**。

回合结束时，玩家手中剩余的普通卡牌进入 Discard Pile。

当抽牌时 Draw Pile 中剩余卡牌不足时：

1. 先抽取 Draw Pile 中剩余的卡牌；
2. 将 Discard Pile 中的所有卡牌移入 Draw Pile；
3. 对新的 Draw Pile 进行洗牌；
4. 继续抽取，直到达到本次应抽数量或没有可抽取的卡牌。

## 死亡规则

任意结算时刻，当角色生命值降为 0 时，该角色立即死亡。

死亡角色所有尚未发生的后续动作全部取消，不再结算。

## 名词对照

|中文|推荐英文|备注|
|---|---|---|
|牌库|**Deck**|玩家拥有的整套卡牌|
|手牌堆|**Hand**|当前持有、可打出的牌|
|抽牌堆|**Draw Pile**|等待被抽取的牌|
|弃牌堆|**Discard Pile**|已弃置或结算完成后进入的牌堆|
|消耗堆|**Exhaust Pile**|本场战斗中被消耗、暂时移出的牌|
|基础牌|**Basic Card / Basic Cards**|卡牌类别用 Basic Card|
|每回合抽牌数|**Cards Drawn Per Turn**|每回合从 Draw Pile 抽取的非基础牌数量|
