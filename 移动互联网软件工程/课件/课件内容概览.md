# 移动互联网软件工程课件内容概览

课程：[移动互联网软件工程](https://selearning.nju.edu.cn/course/view.php?id=422)

本目录保存课程页面“课件”栏目中的全部 2 个 PDF 文件。文件已按网页显示顺序下载，并在课程页面中完成对应的完成状态确认。

## 1. [[00-课程介绍.pdf]]

- 页数：27 页
- 主题：课程总体介绍，以及“AI 原生鸿蒙软件工程实践”的教学目标与项目路线。
- 内容摘要：课件从个性化需求出发，介绍 AI 如何理解用户目标、补充约束，并生成适合当前任务的交互界面。课程强调“对话作为入口、卡片作为操作界面”，由受控工具完成匹配、发布、通知、订单和评价等业务动作，同时保留确认、比较、进度、风险提示和审计能力。
- 课程安排：全课程 18 周、每周 3 小时，共 54 学时，设置 4 次里程碑评审，围绕一个持续演进的系统开展实践。项目方向是将 CampusHub 1.0 演进为校园智能体，而不是重新制作一套传统 CRUD 系统。
- 能力重点：个性化需求工程；人机交互与生成式 UI；基于 ArkTS/ArkUI/Stage 的鸿蒙应用开发；现代语言与并发；AI 原生架构（智能体、模型网关、工具网关和大模型部署）；数据治理与数据飞轮。
- 核心认识：业务规则、安全边界、权限和事实需要稳定、可控；用户目标、工作流和界面可以根据上下文动态生成。课件最后引出“从特殊需求到生成式交互”的后续学习主线。

## 2. [[01-AI原生软件工程与环境搭建.pdf]]

- 页数：54 页
- 主题：AI 原生软件工程的基本概念，以及鸿蒙客户端、智能体后端和端到端开发环境的搭建。
- 内容摘要：课件说明 AI 不只是传统软件中的聊天入口，而是同时参与需求、设计、编码、测试、评审、运维和运行时交互。由于模型输出具有不确定性，工程系统需要明确模型建议、系统校验、用户确认和真实业务执行之间的信任边界，并通过规范、测试、评审、版本、护栏和可观测性控制风险。
- 环境内容：包括 DevEco Studio、鸿蒙 SDK、模拟器或真机、ArkTS，以及后端 API、模型服务、数据库、缓存、流式输出和工具服务等组成部分。
- 验收目标：完成客户端 → 后端 → 模型 → 工具 → 数据库的最小闭环，得到可复现的端到端开发链路，而不是只完成软件安装。课件强调应以真实请求、真实返回、工具调用、数据写入和异常处理等证据证明链路确实运行。
- 核心认识：AI 生成代码并不等于系统完成；应建立“目标 → 规格 → 生成 → 验证 → 运行证据”的工程证据链，并把权限、业务约束、状态机、副作用、数据责任和最终决策保留在可验证的工程控制范围内。

## 学习顺序与关系

《00-课程介绍》用于建立课程全貌、项目背景和能力地图；《01-AI原生软件工程与环境搭建》进入第一章实践，负责建立开发环境、信任边界和最小端到端运行链路。建议先阅读课程介绍，再按第一章完成环境搭建和闭环验收。
